Surface Analysis Extension for SOLIDWORKS

This add-in extends SOLIDWORKS' built-in surface analysis tools with:

  - Isophote and environment (matcap-style) zebra-stripe analysis,
    with adjustable line count, line width, and edge blur
  - User-controllable mesh tolerance and chord angle, giving direct
    control over analysis mesh density and precision -- independent
    of the part's own display quality setting
  - True-surface isocurve display
  - Surface normal visualization
  - G2 (curvature) edge-continuity checking between two faces, with
    live on-screen deviation reporting

Everything is toggled from a single button added to the SOLIDWORKS
CommandManager.

This software is provided free of charge, with no warranty of any
kind.

The add-in has been tested to open and generally operate on 
the following verions of Solidworks. 2017, 2020, 2021, 2023.
The add-in has been extensively tested using SS 2025.
Note the add-in has only been tested using NVIDIA GPU's
